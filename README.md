# Лиза ЖЁСТКИЕЙ ТРЕНЖЁР + Вайб

Визуальная основа сайта для подготовки к ОГЭ и ЕГЭ по истории и обществознанию.

## Что уже заложено

- Главная страница ученика с выбором предмета и экзамена.
- Страница `Регистрация/вход`.
- Учительский макет `/teacher` со списком учеников, поиском и сортировкой.
- Тестовый учитель: `TestTeacher`, пароль `123321`.
- `/teacher` закрыт входом учителя через подписанную cookie-сессию.
- После входа в шапке вместо `Регистрация/вход` показывается имя аккаунта.
- Тестовые ученики лежат в `src/data/students.ts`.
- Подключение к Supabase через переменные окружения.
- SQL-схема базы лежит в `supabase/schema.sql`.

## Как лучше делать приглашения

Лучший вариант для настоящего сайта: специальная ссылка-приглашение, например `/register/LZ-8K2P-MR91`.

Почему так удобнее:

- ученику не нужно вручную переписывать код;
- код всё равно остаётся внутри ссылки;
- учитель может скопировать ссылку и отправить ученику;
- позже можно добавить срок действия и запрет повторного использования.

Поле для ручного ввода кода тоже стоит оставить как запасной вариант.

## Как включить настоящую базу данных

1. Открой Supabase.
2. Перейди в `SQL Editor`.
3. Создай новый запрос.
4. Вставь содержимое файла `supabase/schema.sql`.
5. Нажми `Run`.

После этого страница `/teacher` сможет проверять вход учителя и брать учеников из Supabase. Если таблиц ещё нет или база временно недоступна, сайт использует тестовые данные из `src/data/students.ts`.

Если таблицы уже созданы, но нужно добавить только проверку входа учителя, можно выполнить короткий файл `supabase/teacher-auth.sql`.

Локальные переменные лежат в `.env.local`, этот файл не отправляется в GitHub. Пример переменных есть в `.env.example`.
